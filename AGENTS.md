# AGENTS.md

A standalone binary crate, `affected-crates`: reports the workspace packages a git diff affects, using the `determinator` crate and the caller's rules file. `action.yml` is the composite action that installs the released binary and runs it.

## Commands

```bash
cargo build
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
actionlint
```

## Layout

- `src/main.rs`: the tool.
- `tests/selection.rs`: selection semantics against fixture git repositories created per test.
- `action.yml`: the composite action.
- `dist-workspace.toml`, `.github/workflows/release.yml`: cargo-dist (generated by `dist generate`).
- `release-plz.toml`, `.github/workflows/release-plz.yml`: version and tag PRs.
- `.github/workflows/ci.yml`: build, test, lint, format.
